# ConnectSphere — Frontend

This is the React client for ConnectSphere, a real-time video calling application. See the [root README](../README.md) for full project setup, tech stack, and how the app works.

## Available Scripts

In this directory, you can run:

### `npm start`
Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm run build`
Builds the app for production to the `build` folder.

### `npm test`
Launches the test runner in watch mode.

## Configuration

Before running, check `src/environment.js` and make sure the backend server URL matches your setup (local development vs. a deployed backend).
